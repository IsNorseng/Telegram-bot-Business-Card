# Telegram-бот-визитка

Учебный прототип Telegram-бота для компактной презентации услуг, контактов и навигации по материалам.

## Возможности

- обработка команды запуска;
- кнопки и callback-обработчики;
- разделы с кратким описанием и ссылками;
- заготовки ответов, которые можно заменить на реальные тексты.

## Запуск

Создайте виртуальное окружение, установите зависимости из [requirements.txt](requirements.txt), задайте токен бота через переменную окружения и запустите основной Python-файл. Токен не хранится в репозитории и не должен попадать в исходный код.

## Структура и ограничения

Проект показывает базовую архитектуру асинхронного Telegram-бота и точку для дальнейшего расширения. Это учебная заготовка: нет постоянного хранилища, логирования, тестов и развёртывания. Перед публикацией нужно добавить конфигурацию, обработку ошибок и защиту пользовательских данных.

**Инструменты:** Python, aiogram, Telegram Bot API.
