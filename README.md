# Telegram-бот-визитка

Бот на Python и pyTelegramBotAPI (telebot) с кнопочным меню для знакомства с автором: увлечения и навыки, образование и опыт, достижения, ссылки на социальные сети.

Поддерживает команды /start и /help, отвечает на выбор раздела и предлагает воспользоваться меню при неизвестном сообщении.

[Посмотреть код бота](https://github.com/IsNorseng/Telegram-bot-Business-Card/blob/main/The%20main%20code%20of%20the%20bot)

Для запуска установите библиотеку командой pip install pyTelegramBotAPI, укажите токен в TOKEN и заполните имя и тексты ответов своими данными.
