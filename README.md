Ранний учебный прототип на `pyTelegramBotAPI` (`telebot`): кнопки меню и обработчики текстовых ответов. [Исходный файл](The%20main%20code%20of%20the%20bot).

Это черновик, а не готовый к запуску бот: в коде есть синтаксические ошибки и заглушки ответов. Токен оставлен как placeholder; списка зависимостей и тестов нет.
